# Автоимпорт партнёрских объявлений

`sync-partner-listings.mjs` читает только разрешённые каналы `@runomer` и
`@specznak`. Он сохраняет лишь номер, цену, регион, дату, название источника
и прямую ссылку на пост. Телефоны, имена пользователей и текст поста не
сохраняются.

Перед запуском в безопасной серверной среде задай переменные:

```powershell
$env:EXPO_PUBLIC_SUPABASE_URL = "https://…supabase.co"
$env:SUPABASE_SERVICE_ROLE_KEY = "секретный-ключ-сервера"
node scripts/sync-partner-listings.mjs
```

`SUPABASE_SERVICE_ROLE_KEY` нельзя помещать в `.env` приложения, публиковать
в GitHub или добавлять в Expo: он нужен только на сервере/в CI. Для ежедневной
работы в проект добавлен GitHub Actions: `.github/workflows/sync-partner-listings.yml`.
После загрузки проекта в GitHub открой **Settings → Secrets and variables → Actions**
и добавь два секрета: `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`.

Расписание запускается раз в день в 12:00 по Москве; в разделе **Actions**
его можно запустить вручную. Пока этих секретов и GitHub-репозитория нет,
автоматическое добавление не выполняется — это специально, чтобы не раскрыть
серверный ключ базы.

Импортируются только публикации не старше 24 часов. Старые посты не попадут
в каталог при первом запуске и не будут дублироваться.

Plate glyphs follow the Russian registration-plate character shapes.
Source: https://github.com/stanlapru/rus-carplates-font
Author: stanlapru (2023). License: DO WHAT YOU WANT PUBLIC LICENSE, see LICENSE.txt.
render-plate-glyphs.py rasterizes the font using the actual ink bounds at high resolution.
The component fits these local images into fixed cells, so browser and native font metrics cannot cause overflow.
